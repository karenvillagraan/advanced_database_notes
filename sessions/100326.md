## What I understood
- UNION combines results from two queries and removes duplicate rows
- UNION ALL combines results but keeps duplicates
- DISTINCT removes duplicate values from query results
- INTERSECT returns rows that appear in both tables
- MINUS returns rows that exist in one table but not in the other
- When using set operators the queries must have the same number of columns and compatible data types
